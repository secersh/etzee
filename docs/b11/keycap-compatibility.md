# B11 Keycap Compatibility

B11 keycaps must use MX-compatible stems. This keeps the keycap interface common across the supported switch families, including MX, Choc v2, and KS-33 variants.

| Keycap requirement | Value |
|--------------------|-------|
| Stem | MX-compatible cross stem |
| Switch grid pitch | 19.2 mm x 19.2 mm |
| Supported B11 switch families | `MX`, `CHOC-V2`, `KS-33` |

Low-profile switch variants can still use MX-stem keycaps, but cap height, skirt clearance, and travel clearance need to be checked against the selected switch family and enclosure geometry.
