# Support

etzee is an early open hardware project. Support is community-oriented and best-effort.

## Questions and Discussion

Use the etzee Discord for design questions, build discussion, and coordination:

https://discord.gg/y3pcSCghcg

## Bugs and Reproducible Issues

Use GitHub Issues for reproducible problems with:

- hardware files
- firmware
- scripts and workflows
- documentation

Include the affected path, expected behavior, actual behavior, and reproduction steps.

## Security

Do not report security issues publicly. See [SECURITY.md](SECURITY.md).
